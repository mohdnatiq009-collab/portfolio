# Mohammad Natiq — Personal Portfolio Website

> **"Code. Learn. Solve. Grow."**

Modern, colorful, and interactive personal portfolio and digital resume for **Mohammad Natiq** (Computer Science & Engineering Student & Aspiring Software Developer at Lovely Professional University, Punjab).

---

## 🚀 Live Demo & Preview

- **Local Preview**: `http://localhost:5173`
- **GitHub Pages**: Deploys automatically via GitHub Actions upon pushing to the `main` branch.

---

## 🛠️ Tech Stack & Architecture

- **Core**: React 19, TypeScript
- **Styling**: Tailwind CSS, Custom Glassmorphism, CSS Gradients
- **Icons**: Lucide Icons & Custom Brand Vectors
- **Build Tool**: Vite
- **Deployment**: GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

---

## 🌟 Key Features

1. **Modern Hero Section**: High-resolution profile card, live internship availability pill, and floating technology badges (Python, C, C++, JavaScript, HTML, CSS, MySQL).
2. **Developer Journey Timeline**: Interactive milestone tracker from Class X (ICSE) and Class XII (TS Board) to B.Tech CSE at Lovely Professional University (2025–2029).
3. **8-Panel Visual Storyboard Lightbox**: Narrative comic overview illustrating Mohammad Natiq's goals and philosophy.
4. **Interactive Skill Universe**: Categorized technical dashboard with real-time detail inspector.
5. **Flagship Projects Showcase**:
   - *Modern Safety Device with Exact Location* (IoT / Hardware / Emergency Location Alerting) with full architectural modal deep-dive.
   - *Code Bug Finder* (Software / Static Analysis) featuring an interactive 4-stage visual flow (*Problem → Analysis → Detection → Feedback*).
   - Foundational coursework in C systems programming, relational databases (3NF SQL), and cybersecurity research.
6. **"How I Approach Problems" & "Build With Me"**: 4-step cognitive problem-solving framework and 6-stage development mindset pipeline.
7. **Currently Learning Lab**: Honest, transparent skill-growth indicators (*Building, Practicing, Learning, Exploring*) without fake percentages.
8. **Interactive Terminal**: Full-featured in-browser developer CLI simulator (`natiq@developer-terminal:~`) accepting commands like `skills`, `projects`, `whoami`, `education`, `philosophy`, and `help`.
9. **Digital Resume & CV**: Direct in-browser PDF preview modal and one-click download for `Mohammad_Natiq_Professional_CV.pdf`.
10. **Theme Switcher**: Instant Dark / Light mode toggle with smooth styling transitions.

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build production bundle**:
   ```bash
   npm run build
   ```
